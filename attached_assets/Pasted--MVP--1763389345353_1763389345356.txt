Создай полный код для минимально жизнеспособного продукта (MVP) веб-сайта "РобоКвест" — виртуальной лаборатории по робототехнике с элементами геймификации. Сайт должен быть простым, работать в основном на клиентской стороне (без backend, базы данных или серверов для MVP), использовать vanilla JavaScript, HTML5 и CSS. Для UI используй Bootstrap 5 (укажи ссылки на CDN). Для симулятора физики используй библиотеку Matter.js (тоже через CDN).

Ключевые требования к сайту:

Главная страница (index.html): Это стартовая страница. Добавь раздел с информацией о сайте:
"Что это?" — Краткое описание: "РобоКвест — виртуальная лаборатория по робототехнике для школьников и студентов, где вы собираете роботов, программируете их и решаете задачи в игровой форме."
"Как работает?" — Объяснение: "Выберите уровень, соберите робота из деталей, запрограммируйте простые команды, запустите симуляцию и получите обратную связь. Уровни разблокируются по мере прогресса."
"Зачем нужен?" — Преимущества: "Доступное обучение без оборудования: развивает навыки программирования, физики и инженерии через игру. Мотивация через баллы и достижения."
Кнопка "Начать" или "Войти", ведущая к регистрации/игре.
Регистрация: Простая форма на главной странице (или в модальном окне): поля для username, email, password. Используй localStorage для хранения "учётки" локально в браузере (фейковая регистрация без сервера). После "регистрации" сохрани данные и перенаправь на страницу с уровнями. Если пользователь уже "зарегистрирован", покажи приветствие и кнопку "Продолжить". Добавь простую "авторизацию" (проверь localStorage).
Структура сайта: Главная (index.html) с инфо и регистрацией. После регистрации — переход на game.html с разделами: конструктор робота, симулятор, обратная связь и прогресс. Добавь 3 уровня (задания) как отдельные модальные окна или разделы, которые разблокируются по прогрессу (используй localStorage для сохранения прогресса).
Конструктор робота: Простая форма с выпадающими списками (select) для выбора деталей: количество моторов (1-2), тип датчика (нет, линия, ультразвуковой), микроконтроллер (Arduino или Lego). Кнопка "Собрать" генерирует объект робота в JS и отображает описание/простую схему (текст или canvas-рисунок).
Симулятор физики: Используй Matter.js для 2D-симуляции. Робот — как тело (rectangle) с колёсами. Окружающая среда: земля, препятствия, цель. Пользователь "программирует" через простые команды (например, input для скорости/направления). Симуляция запускается кнопкой, учитывает гравитацию, трение, инерцию. Проверяй успех: время < 3 мин (симулируй секунды), энергия < 50% (простой расчёт).
Геймификация: Локальное хранение прогресса (localStorage): уровни (1-3), баллы за успех. Достижения: +10 баллов за задачу, разблокировка следующего уровня. Обратная связь: текст с объяснением ошибок (например, "Робот упал из-за инерции — добавьте стабилизаторы").
Задания (уровни):
Простое: Запрограммировать робота на движение по прямой линии до цели.
Среднее: Избежать препятствий с помощью датчика.
Сложное: Доставить "груз" (добавь объект), с ограничением по времени/энергии (как в примере: доставка медикаментов в больнице).
Интеграция с реальным миром: Кнопка "Экспортировать код" генерирует простой Arduino-подобный код в textarea для копирования.
Дизайн: Responsive, простой и привлекательный. Canvas для симулятора (800x400). Добавь инструкции и подсказки на главной и игровой страницах.
Упрощения: Нет мультиплеера, командной работы или видео. Всё на клиенте. Сайт должен работать локально (открой index.html в браузере) и легко деплоиться на GitHub Pages.
Выведи полный код в отдельных блоках:

index.html (с CDN для Bootstrap и Matter.js, с инфо и регистрацией).
game.html (страница с конструктором, симулятором и уровнями).
styles.css (общий для всех страниц).
script.js (с логикой регистрации, симуляции, конструктора и геймификации; используй для обеих страниц). Добавь комментарии в коде для ясности. Убедись, что код работает без ошибок. Если нужно, протестируй в уме.
